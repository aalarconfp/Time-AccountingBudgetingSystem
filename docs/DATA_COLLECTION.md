# Data Collection SOP

## Objective

Collect complete, period-bounded source data before any reconciliation.

## Required sources

1. ActivityWatch laptop
2. ActivityWatch desktop
3. Apple Screen Time
4. Habit / Off-Device

## Collection principles

- Preserve original exports.
- Do not edit source exports.
- Record collection date if practical.
- Keep source/device identity.
- Confirm start/end coverage.
- Resolve gaps before close.

## ActivityWatch

Use the detailed procedures in:

- `ACTIVITYWATCH_LAPTOP.md`
- `ACTIVITYWATCH_DESKTOP.md`
- `README_ACTIVITYWATCH.md`

## Apple Screen Time

Keep the original export and process it through the source-specific pipeline.

Never manually modify final Apple records to compensate for unrelated
ActivityWatch attribution corrections.

## Habit / Off-Device

Review manually entered activities for:

- completeness;
- obvious duplicates;
- obvious overstatement;
- intended period boundaries.

## Collection sign-off

Before processing:

- [ ] All sources collected.
- [ ] All dates covered.
- [ ] Device/source identity correct.
- [ ] Source files preserved.
