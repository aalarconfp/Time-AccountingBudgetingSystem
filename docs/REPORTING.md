# Reporting SOP

## Reporting layers

### Final Analysis

Technical reconciled dataset.

### EDA

Deep analytical diagnostics.

### Standard Report

Recurring management summary.

## Standard Report KPI set

### Time accounting

- Clock Capacity
- Unique Tracked
- Off-Device Life
- Tracked Overlap
- Analytical Activity

### Goal

- Investment
- Maintenance
- Consumption
- Investment ratio

### Energy

- Recovery
- Deep
- Active
- Shallow
- Passive

### Discretionary consumption proxy

Current proxy:

- Games
- Entertainment
- Social Networking

when classified as Goal=Consumption.

## Standard Report philosophy

Keep it small.

The report should identify:

1. where time went;
2. investment/maintenance/consumption balance;
3. recovery;
4. discretionary drains;
5. next-period attention areas.

Use EDA for everything deeper.
